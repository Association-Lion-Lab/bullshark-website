Install

Download the Linux binary, run it, then open http://localhost:4991.

Open ports 4991/tcp and 40000 tcp+udp. On first launch, keep the owner token printed in the console.

Full guide 
# ARM (Raspberry Pi): bullshark-linux-arm64
$ curl -L https://github.com/Neckript/bullshark/releases/latest/download/bullshark-linux-x64 -o bullshark
$ chmod +x bullshark
$ ./bullshark
# No published image yet: build from source.
# Build the server binary first (see the guide).
$ git clone https://codeberg.org/The_Neckript/bullshark.git
$ cd bullshark
$ docker build -t bullshark:local .
$ docker run -d \
    -p 4991:4991/tcp \
    -p 40000:40000/tcp \
    -p 40000:40000/udp \
    -v ./data:/home/bun/.config/bullshark \
    --name bullshark \
    bullshark:local
